# Iron Tide Update Notes — Gameplay Polish Pack

## Combat visual polish
- Added quality-aware projectile halos and brighter projectile cores for shells, rockets, artillery, and acid shots.
- Added short-lived turret-direction muzzle flashes driven by the existing recoil simulation.
- Added subtle ground shadows and pulsing friendly selection rings for clearer unit readability.

## Unit command feedback
- Selected units now show animated dashed movement routes and destination markers.
- Attack-move orders use amber markers; ordinary movement orders use cyan markers.
- Existing selection, order, and multi-touch gestures remain in place.

## Camera, animation, destruction, and audio
- Preserved the existing smooth camera easing, drag-pan, mouse-wheel zoom, and two-finger pan/pinch zoom.
- Preserved existing infantry gait, vehicle recoil, helicopter rotor animation, and zombie animation systems.
- Preserved existing building damage, fires, rubble, and crater effects.
- Preserved existing synthesized weapon, vehicle, zombie, command, and mission audio.

## After-action report
- Expanded mission results with kills, surviving units, unit losses, sectors secured, civilians rescued, and operation time.
- Added a performance grade (S–D) calculated from sector control, civilian evacuation, and unit retention. This is a display-only score and does not change rewards or gameplay balance.

## Compatibility
- No unit cap added.
- Existing coin economy and combat values are unchanged.
- No new image or audio assets required.
